DERIVATION:
  Step 1 (from F2) per [CR 100.1b] "A multiplayer game is a game that begins with more than two players." => Each game of this match is a multiplayer game
  Step 2 (from F1, F2, F3, F4, F5, F6, S1) STIPULATION (the rule's own new content, no source) => When time is called, only completed games count (a running game is finished first, with extra turns and then a draw if undecided; drawn games count for nobody). The player with the most game wins takes the match; players tied for the most wins draw the match among themselves, and players outside the tied top lose.
