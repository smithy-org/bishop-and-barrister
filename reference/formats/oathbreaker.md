# Oathbreaker

Oathbreaker isn't in the CR. Its rules are on oathbreakermtg.org, a community-run site (level 2, for this format
only), written as if they were a CR section 906. **That numbering is the site's own: the CR's variant sections
stop at 905.** Cite it as "Oathbreaker rules 906.x", never as a CR number.

| Rule              | Value                                                                                   | Oathbreaker rules |
| ----------------- | --------------------------------------------------------------------------------------- | ----------------- |
| Players           | A multiplayer free-for-all by default, attacking multiple players                        | 906.2             |
| Oathbreaker       | A planeswalker (a double-faced card's front face must be one); two with Partner           | 906.3, 906.3a-b   |
| Signature Spell   | An instant or sorcery within the Oathbreaker's color identity; one per Oathbreaker         | 906.4, 906.4b     |
| Deck              | Exactly 60 cards, including the Oathbreaker and the Signature Spell                      | 906.6a            |
| Copies            | One of each card by English name, basic lands excepted                                   | 906.6b            |
| Colors            | Every card within the Oathbreaker's color identity                                       | 906.5, 906.6c-d   |
| Card pool         | Vintage-legal cards, minus Oathbreaker's own banned list                                  | 906.6f            |
| Starting life     | 20, seven-card hands                                                                     | 906.8             |
| Outside the game  | Abilities that use cards from outside the game don't work                                | 906.13            |

- **The command zone:** the Oathbreaker and the Signature Spell both start there (906.7), and each costs {2}
  more for each earlier cast from there that game (906.9, 906.11). The Signature Spell can be cast only while
  its Oathbreaker is on the battlefield under its owner's control (906.4a, 906.11).
- **Leaving play:** the Oathbreaker *may* go to the command zone instead of exile, hand, graveyard or library
  (906.10). The Signature Spell *must* (906.12), and anywhere but the stack or command zone sends it back to the
  command zone, ahead of effects like buyback (906.12a).
- **Effects that say "commander"** refer to the Oathbreaker (906.14).
- **Mulligans and the first draw:** the rules don't say; the FAQ gives every player a free London mulligan and a
  draw on their first turn, the starting player included, "just like in other multiplayer games". It doesn't
  address two-player games.
- **Banned list:** oathbreakermtg.org/banned-list (latest update February 2026). It doesn't use Commander's
  "Game Changers" list.

Sources: https://oathbreakermtg.org/rules/ and https://oathbreakermtg.org/faq/ (checked 2026-10-26).
