# Brawl

There are two: the CR's Brawl (60 cards) and MTG Arena's Brawl (100 cards). Scryfall, and so `card.py`,
calls the CR's version "standardbrawl" and Arena's "brawl".

## The CR's Brawl

The Commander rules, with these changes (CR 903.12a).

| Rule             | Value                                                                       | Source (level)         |
| ---------------- | --------------------------------------------------------------------------- | ---------------------- |
| Card pool        | Usually the Standard format's cards                                         | CR 903.12b (1)         |
| Commander        | A legendary creature, planeswalker, Vehicle, or Spacecraft that meets 903.12c | CR 903.12c (1)       |
| Deck             | Exactly 60 cards, including the commander                                   | CR 903.12d (1)         |
| Colorless commander | Any number of basic lands of one basic land type                         | CR 903.12e (1)         |
| Starting life    | 25 with two players, 30 with more                                           | CR 903.12f, 103.4d (1) |
| Mulligans        | The first mulligan is free in any Brawl game                                | CR 903.12g, 103.5c (1) |
| Commander damage | Doesn't apply: no loss at 21                                                | CR 903.12h (1)         |

## MTG Arena's Brawl

| Rule          | Value                                                              | Source (level)            |
| ------------- | ------------------------------------------------------------------ | ------------------------- |
| Deck          | The commander and 99 other Brawl-legal cards in its colors          | Wizards' Brawl page (1)   |
| Games         | One-on-one, best of one, with a free mulligan; no sideboard         | Wizards' Brawl page (1)   |
| Starting life | The page doesn't say; the CR's two-player Brawl value is 25          | CR 903.12f (1)            |

Source: https://magic.wizards.com/en/formats/brawl (checked 2026-10-26).
